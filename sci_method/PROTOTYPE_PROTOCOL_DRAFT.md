# 最小原型实验方案（草案，待审查冻结）

**阶段：**探索性数学/算法原型提案。尚未获准作为正式冻结验证方案；本轮没有运行。

## 1. 目标与可证伪假设

目标是验证“可辨识性校准的自适应分辨率似然重建”（ICAR-LR）是否在有限事件数和击中位置误差下，能避免固定细网格似然的过拟合/噪声，同时比固定粗网格保留更多可验证结构。

候选假设（需要研究者改写/冻结）：

> 在相同事件、同一散射似然、相同误差模型和预定的假阳性约束下，基于观测信息决定的局部 split/merge 可使边界/定位误差相对固定粗网格改善，同时不劣于固定细网格在可恢复区域的误差；当局部信息不足时，算法应拒绝细分并表现为低置信度，而非输出高置信伪结构。

该假设尚无数据支持，不能写成研究结论。主评价指标、非劣界、成功阈值和多重比较处理需要实验前冻结。

## 2. 最小方法原型

先在纯 Python 数值单元测试中建立：

1. 由一个已知散射密度体素/小块和解析路径长度得到多重散射协方差。
2. 为四层 detector hits 构造二维上游线和下游残差，并传播 hit-coordinate covariance。
3. 验证无材料/零散射极限、协方差对称半正定、单位尺度、极限 case（零误差、近竖直径迹）及数值有限性。
4. 在未使用目标真值的情况下计算对体素参数的似然梯度或有限差分灵敏度；检查可辨识矩阵退化方向。
5. 只有上述测试通过后，才对小型预定义几何做探索性拟合；网格细分策略先仅与固定粗/细分辨率对照，不引入神经网络。

实际模型形式（观测量、参数化、误差传播、动量 nuisance、正则项、优化器）需先根据 MINT/RHMT/MLS-EM 文献和代码核验书面冻结。

## 3. 比较组

相同原始事件、共用事件集合、相同视场、相同数据预处理；所有真值均与推断程序隔离。

1. 固定粗分辨率统计似然（保守方差/偏差参照）。
2. 固定细分辨率统计似然（分辨率上界但低计数高方差参照）。
3. 固定网格 + TV/明确先验正则（避免把“有正则”误当自适应创新）。
4. ICAR-LR（唯一变化是基于预定信息准则的局部 split/merge 和相应置信输出）。
5. 历史方法：PoCA、ASR；可获取且可复现时纳入 MLS-EM、μTRec、MINT、RHMT/NAMT。若无法复现某近邻，必须报告原因，不能静默排除或只和 POCA 比。

需要有公平性控制：每种方法使用同一事件预算与已知 hit noise，调参数据/预算一致；允许方法原生需要不同事件字段时，另行报告信息不对称。比较应包含运行时间/内存，但不得以工程速度代替图像正确性。

## 4. 分阶段数据方案

### Stage A：解析/单元与玩具场景

- 手工固定的小型体素场和确定性路径，只测 forward covariance/likelihood，不生成 Geant4 数据。
- 用独立 seed 的玩具高斯扰动验证 estimator 校准；标签只由测试端脚本持有。
- 无可声明的成像性能结论。

### Stage B：已有 Geant4 CSV 的开发性接口验证

- 输入候选：`muon_analysis/muon_tracks.csv` 的四层击中列；不读取该 CSV 的 PoCA/角度列。
- 该文件已查看，物理随机流未知，仅为开发集/管线验证；不得切分后称冻结验证。
- 旧 `detector_resolution_results/` 是已查看误差研究。若重用其误差范围，标为方案探索参考而不是独立验证；原 CSV 只读，派生扰动不回写。
- 不因这一步读取真值 mask 来挑模型/阈值。

### Stage C：新物理仿真/冻结验证（单独审查批准）

- 当前不运行。实施前先冻结具体场景、材料/厚度、源谱、事件预算、探测器分辨率/对准误差模型、随机流、几何真值与 blind 管理人。
- 开发/调参场景与最终测试场景按几何、材料和物理 RNG 隔离；设计算法的人不得提前访问最终测试结果。
- 至少需要真实变化而非重复同一 U 型场景：位置/尺寸/材料/组合和误差条件的覆盖规则由研究者事先指定；事件子抽样不等同于独立模拟。
- 输出应含 protocol/config/provenance、原始事件数、四击中完整数、筛选后数、参与拟合数、输入哈希、代码 SHA、物理/分析 RNG、精确命令和测试日志。

## 5. 指标候选（尚未确定主指标）

候选组而非当前方案：

- 目标定位误差、边界/表面距离误差；
- 不同空间频率下的恢复/分辨率，以及分辨率—事件数曲线；
- 固定假阳性率下的检出灵敏度或 pixel/region ROC-AUC（掩膜只供冻结后的评价程序）；
- Brier score / 置信区间覆盖率 / 可靠性曲线，用于检验不确定度是否校准；
- 纯仿真可报告体素密度误差、SSIM 等辅助指标，但不得只靠真值面积 Top-k IoU。

必须预先选定一个 primary endpoint 和成功标准，并指定估计单位（独立物理 run、独立场景，或事件级重复抽样）；不得把同一 run 的相关重采样当独立重复。若没有盲测或独立物理 RNG，论文限定为仿真开发研究。

## 6. 必要消融

若 ICAR-LR 主候选获批，建议最小消融：

- detector covariance 正确传播 vs 忽略/错误设定；
- 固定尺度 vs 信息驱动尺度；
- 仅计数驱动 vs Fisher/后验信息驱动；
- 是否报告/使用局部不确定性；
- 粗、细、适应网格在相同计算/参数预算下的敏感性。

这些消融问题需在查看结果前选定；不得按结果挑选“有利”的组合。

## 7. 运行前放行检查

在开始任何 Geant4 或大规模算法实验之前，需完成并审查：

- 可追溯的文献查新表与近邻方法代码/公式逐项比较；
- forward model 的量纲、PSD、极限和梯度测试；
- 空间可辨识性分析计划，尤其 z 向分辨率和有限角范围；
- 主基线的复现/输入信息对齐计划；
- development/tuning/frozen-validation/final-unseen 各自场景与权限；
- 研究者冻结的 primary metric、成功标准、排除/失败处理和报告方法；
- 独立输出目录、配置、随机流和哈希记录方案。

任一项未完成即暂停，不自动运行大实验。

# B2：独立统计审查与机器学习增量

完成日期：2026-10-26。这是方法学审查，不是已验证的新算法。数学反例与单位见 [MATHEMATICAL_REVIEW.md](MATHEMATICAL_REVIEW.md)。

标记：[证明] 限定模型下成立；[数值] 确定性计算；[文献] 引用作者原文；[假设] 待验证；[未知] 尚不能确认。

## 1. A：固定结构对比＋独立统计审查

设观测为 D、预先声明的结构对比集合为 H，物理统计模型及校准信息为 M，审查器为 R(D,H,M)。CNN 输出 gφ(D)，MAP 输出 m(D)。若 R 不读取任何候选图像、其参考点或由候选图像选择的区域，且输入、数值精度、校准及必要的算法随机流相同，则

`R_CNN(D,H,M) = R_MAP(D,H,M)`，对每一个 D 都成立。[证明：同一个函数、同一组输入。]

因此固定对比的支持、拒判、profile 区间和检验功效不能因前端 CNN 而改变。若 CNN 只展示其中一部分对比，那是展示/选择变化，不能叫审查器功效提升。若把 CNN 估计代入 Fisher、nuisance 或优化初值并改变最后结论，必须另查参考点、估计误差及优化精度；此时已不属于严格的 A。近似优化结果不同不是新增物理信息。

ML 仍可改善独立场景上的点重建误差、任务效用、迭代初值或运行成本；收益来自训练分布先验或计算方式，而不是改变相同似然中的信息。[假设] 简单串联“CNN＋独立审查器”没有自动成立的 ML 方法创新。

**对前一轮草案的纠正：**若将固定对比、同一审查器的正确支持率提升作为 CNN 的独立收益，该主张撤回。旧 feasibility 文件保留原状供溯源，以本审查限定其解释。不能把审查器本身的可靠性转移记在 CNN 名下。

## 2. B：ML 提出候选结构＋统计审查

### 2.1 选择后偏差确实存在

网络即使在完全独立的训练场景上训练，也仍会用当前对象的 D 选择“最显著区域”。随后将该区域当成事先固定、继续使用 D 检验，会双重使用观测。训练集独立不能消除这一选择偏差。[证明/文献]

直观反例：20 个独立、均匀零假设 p 值中选最小者，再按 0.05 判断，整次误报为 `1-0.95^20 = 0.641514`。这只是明确概率模型的解析计算，不是假装本项目 20 个区域独立，更不是缪子实验结果。

### 2.2 三种可行但有代价的保护

**事件拆分。**用 Dp 提议区域，Da 审查。给定真实材料场、测量模型及 nuisance，要求两部分独立，且审查的 p 值对给定 Dp 后的每一个所选复合零假设有效。令 K=|S(Dp)|，固定区域、方向和对比后，在 Da 上使用有效 p 值及 Bonferroni α/K，则条件 FWER≤α；K=0 时不声明支持。这个证明要求 p 值对所有允许的其他材料/nuisance 成立，不是只在拟合值附近成立。

共同对准误差、共享校准估计、同一母事件重抽样可破坏简单独立性。应按独立事件/运行或层级模型处理；不能把共享校准当已知常量。提议之后不能看 Da 的结果再移动区域、选择正负方向、调整网络或挑选最好一次拆分。必要时拆分的代价为 Fisher 约从 F 降到 rF、局部信噪比降到 sqrt(r)；一半事件约损失29.3%的局部信噪比。这是理想同设计近似，不是保证。

**全家族同时保护。**预先定义完整有限对比族 H，先构造覆盖全部 H 的同时区间或控制全族 FWER 的检验，再允许 ML 选展示子集。只要全族保证成立，任意同数据选择的子集仍受保护。此时 ML 不能胜过“展示全部已支持对比”的统计发现总量；可能节省搜索/展示成本。对连续可变 ROI，不能只对最终 K 个区域做未经选择修正的 Bonferroni。

**直接选择后推断。**显式条件化网络选择事件，推导条件分布。已有 CNN 分割选择后推断研究，不是空白。它们的 Gaussian **均值**模型和已知协方差，不能直接给本项目参数相关协方差、非负边界、未知背景提供有效 p 值。[文献] 在本问题证明、实现与校准成本最高，暂不作为最低成本入口。

FDR 只控制发现中平均错误比例，不等于整幅图像“至少一处错误可信结构”的 FWER；两者不能互换。独立场景 calibration 可以验证冻结流程的**场景分布边际风险**，但不自动给出逐对象、任意 OOD 或逐区域条件保证。

### 2.3 目前真正的数学缺口

现有 Fisher 可估计性、设计功效及收敛良好的协方差 NLL，**尚不构成一般复合结构零假设的有限样本有效检验**。plug-in bootstrap、局部渐近 χ²、正则化 Hessian 都不能无证明地替代这一点。profile 的全局优化也不能仅由局部 KKT 认证。路径由带噪 upstream hits 估计时还有 errors-in-variables 问题。

所以本轮不能声称已经具备有保证的 B，也不应先训练网络再补统计保证。[未知/阻断训练的设计缺口，不是本轮发现旧 FE 有效区间公式错误。]

一个可先研究的收缩问题：只允许一个非负 ROI 参数 u，其余区域及测量 covariance 已知，`C_i(u)=C_i0+u D_i`、D_i 半正定，检验 H0:u≤u*。统计量 `T=Σ y_iᵀ C_i(u*)^-1 y_i` 在 H0 下被 χ²(4N) 随机上界支配，因为每个白化 covariance 的特征值≤1。由此得到保守的单侧有限样本 p 值。[证明：Gaussian 正交对角化及逐项 χ² 耦合。] 该工具可能功效很低，也不解决一般正负子区对比或未知背景；仅建议下一阶段首先证明/核查它，不在本轮新增算法或模拟。

## 3. C：点重建与可信度说明分离

可以输出两件不同的东西：

1. **先验辅助点估计图**：明确由训练分布/正则化补全，不给每个细节贴“数据证实”。
2. **独立结构证据表/图层**：仅对预声明或有效选择后的结构对比报告支持、区间、无法确定及模型适用条件。

未支持不等于“已证明不存在”。p 值不是材料存在概率；网络方差头不是频率置信区间；模型预测 NLL 好也不能认证零空间中的结构。数学反例说明相同观测可能对应不同真值，不能只展示先验偏好的那一个图。[证明]

即使 CNN 与 MAP 的证据表完全相同，只要在真正独立的母场景上，CNN 的点重建、下游效用或**全流程**成本有可复现优势，C 仍可能有价值。[假设] 但“给图像加一张同样的证据图”本身不是新 ML 算法；需承认经典方法也能使用这套说明。

## 4. 四类增量的公平定义

| 候选增量 | ML 可以改变什么 | 必须与 MAP＋相同审查器比较什么 | 不成立的归因 |
|---|---|---|---|
| 点质量 | 训练先验导致的平均估计风险、形态恢复 | 相同母场景、同观测预算、强 TV/平滑/其他合理先验 MAP；报告三维与投影分别的误差、假结构、先验冲突/OOD | 图片漂亮=数据可辨识 |
| 发现效率 | 给定 K/审查预算下提出更有用的结构 | MAP/标准化 score/覆盖启发式提出候选，同拆分和有效检验；完整真结构族作分母 | 只在被选区域报告成功率 |
| 可靠与信息保留 | 固定风险约束下保留更多有效发现/任务质量 | 相同 FWER 或明确的场景风险，完整拒判率、漏检率、覆盖及拒判后效用 | 大量拒判=更有用；同审查器的有效性=ML增益 |
| 计算 | 初值、近似优化及搜索分配 | 训练＋推断＋物理修正＋审查＋校准总成本，且同 NLL/KKT/风险要求 | 只计网络一次 forward |

只在同一个目标函数/单位/动量/测量模型下比较优化速度。PoCA、MLS-EM、MINT 的任务、输出或正则化不同，应分别给质量/成本和适用范围，不把非等价 NLL 混排。ICAR-LR/BIC/LRT 对局部分裂的基线作用保留，但尚未证明 ICAR-LR 占优。小问题上经典方法可能已经足够。

## 5. 至多两个可证伪假设（均未批准实施）

### H1：固定小候选预算下的学习型结构排序

**问题：**在相同总事件预算与错误可信结构风险约束下，ML 能否比经典提议器发现更多可被独立数据支持的真结构？

**定义：**预声明有限区域对比 H；Dp 上由学习排序器从可观测粗 MAP、标准化 score 与覆盖特征选 K 个对比；Da 上执行同一有效检验及家族保护。输入不含真值、粒子真值身份或 oracle mask。真值只用于训练标签/最终评价并严格隔离。ML 独有操作是跨独立母场景学习有限预算的候选排序，不是给 p 值加神经校正。

**最近工作/差别：**Duy 等已经研究 CNN 分割后的选择推断；MINT 已有神经表示的逐径迹拟合；TaskUQ 已有任务级边际覆盖。这里待验证的差别只在**协方差逆问题、nuisance 与候选预算**下的有效发现效率，不是首次“CNN＋可信度”。若一般检验有效性无法解决，应收缩假设或终止，不能用名称掩盖。

**强基线：**MAP contrast 排序、标准化 score、覆盖启发式、简单线性排序、全固定家族检验；相同训练/开发信息、Dp/Da、K、校准及总成本。全族基线检验成本较高但不可故意排除。

**独立指标：**每场景正确且获支持结构数/完整可评价真结构数，整幅图像至少一处错误支持率、拒判/漏检、独立观测预测 NLL及全成本。风险上限、效应量、K、事件拆分比例均须审查后事先冻结，不能本轮自行指定成正式标准。

**最低数据/成本：**先做不训练的有限家族、手工场景与 oracle 候选预算上界检查；若最佳可能提议都没有增益空间，立即停止。后续才讨论少量独立母场景的线性排序器，仍需新批准及样本量设计；CNN 不应先行。

**失败条件：**拆分损失超过候选筛选收益；经典排序同样好；只有删掉困难场景才有收益；未知背景下 p 值失效；跨场景变化后风险不受控。失败仍可留下有效检验及“选择成本抵消学习收益”的结论，不宣称 ML 创新。

### H2：不改变统计目标的学习型求解初值

**问题：**对大量独立对象重复求解时，学习初值能否在保持同一 MAP 目标与数值认证的条件下减少总成本？

**定义/操作：**学习器输出非负场初值，随后由原物理优化器修正到事先要求的目标值、KKT 及可信审查精度；不以网络输出直接宣称统计支持。不改变 λ 的单位、测量 covariance 或正则目标。这不创造数据 Fisher。[假设]

**差别与新颖性风险：**MINT 是逐扫描神经场优化，非自动等同跨扫描摊销初值；但学习求解器、展开式物理更新和 warm start 本已广泛存在，不能把应用迁移当实质方法创新。目前没有证据证明本假设超过成熟优化技术；查新仍未完成。

**强基线：**零/均匀/粗尺度解 warm start、多尺度 continuation、原预条件求解器、成熟有界优化器；同最终 NLL/KKT、相同对比证据和停止条件。对非唯一解应比较 covariance/预测与可估计对比，不能只比参数距离。

**增量/预算：**总成本 `Ttrain + M(Tinfer+Tcorrect+Taudit)`，经典为 `M(TMAP+Taudit)`。仅当分母 `TMAP-Tinfer-Tcorrect>0` 且 `M>Ttrain/(TMAP-Tinfer-Tcorrect)` 才有摊销回本；Taudit 占主导时总加速有限。需要报告训练失败、校准和开发成本，不只成功模型的推断。

**数据要求：**若后续获批，训练对由独立母场景的可观测输入和认证经典解组成；每个标签也有求解成本。非唯一解需约定等价类/输出目标，不能把某次任意解当唯一真值。先以低维问题审查成本，再按母场景隔离训练/开发/最终测试；本轮不确定训练集规模，不生成标签、不训练。

**失败：**修正后不比经典快；只在放松收敛要求后快；解/证据不一致；实际扫描量不足回本；无方法新意。最小筛查先计经典流程成本和替代初值，不训练。若无 headroom 放弃 H2；可能留下优化与可辨识性诊断，而非 ML 优势论文。

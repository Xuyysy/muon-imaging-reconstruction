## 3. 重新解释64 calibration、128 test

**64并非一概不够。**标准split-conformal，n=64、α=.05，秩`ceil(65*.95)=62`，在交换性及无平局的理想情况下边际失覆盖为3/65≈4.615%。有限样本秩分辨率1/65。该保证不是逐场景、逐材料、任意OOD保证；多结构需用同时得分或另作多重性处理。若场景相关，不能把64当64个独立校准单位。[文献/数值]

另一个不同问题是**独立、冻结后的风险审计**：0/64失败时，单侧95% Clopper–Pearson上界为4.573%，确实低于5%。因此不能武断说64不可能支持5%风险；但零失败结果并未发生，本轮只是算上界。真正风险5%时，观察零失败的概率仅0.95^64≈3.752%。有失败时上界会升高。用于选阈值/调模型的calibration数据不是这份独立审计证据。

**128能否发现ML收益取决于终点和相关性。**以每场景一个配对二元“成功”终点、真实改善5个百分点为规划例，exact双侧McNemar、α=.05：

| 两方法discordance q | n=128规划功效 |
|---|---:|
| .05 | .6216 |
| .10 | .3339 |
| .25 | .1533 |
| .50 | .1025 |

这些是预设概率的有限和，不是本项目发现率，也不是以未知测试结果估计功效。均不到通常80%的规划参考；不因此擅改已冻结研究标准。对IoU、NLL等连续配对终点，需独立开发信息估计配对方差、最小有意义差异和聚类结构，不能直接使用本表。需要多个主要指标时应预声明主次和多重比较规则。

所以撤回“512总场景、固定256/64/64/128即可”的通用建议，保留为历史草案。没有获批的新样本量；先选可证伪终点再定样本数。

## 4. 数据隔离和可复现性

母场景ID至少绑定真实几何、材料组合、尺寸/位置的生成谱系；同母几何的事件随机流、旋转、裁剪、噪声增强、统计预算子样本必须处于同一train/dev/cal/test组。简单hash文件并不能识别近重复几何，还要保留生成参数和父ID。

所有既有历史场景默认开发资产；目录移动、改名、换种子不令它们重新成为未见测试。测试场景的形状/材料组合/覆盖/预算分层应在实验前声明，不从成功图反推OOD类别。对同场景多次事件抽样，误差条按母场景聚类，不能当独立物理重复。

训练标签可读真值，但推断输入只含探测器可得观测/经校准的几何和响应。Geant4 PDG/Track/Parent ID仅供生产身份审计，不能作网络常规特征；oracle mask、Top-k及真值区域只供监督或评价，不进入测试推断和细分决策。

已知固定4 GeV/c前向模型与旧Geant4的4 GeV动能不同；后者μ动量约4.1043 GeV/c（含muon静质量），不能默认为同一源。将来物理迁移必须使用记录的动量/源条件并审查beta、能损、空气/探测器散射、路径估计误差和非Gaussian尾。本轮不为修正此差异修改旧源或数据。

每个新run独立目录，配置、种子/无随机性声明、输入哈希、源码SHA/快照、环境、命令、失败状态和输出哈希齐备；历史输出只读。已有单位测试与确定性核查不等于真实实验数据证据。尚未确认有授权实测数据，无实测时最多主张模型内数学/独立仿真证据，不宣称sim-to-real。

## 5. 申请第一轮CNN训练的必要条件

1. H1或H2中只选一个，研究者批准可操作的独立增量及停止标准；不能只说“物理约束网络”。
2. 审查器适用范围和风险保证可证明或明确限定为经验边际校准，不夸大。
3. 非神经强基线、oracle headroom及数据/总成本可行性足以支持训练，而不是已证明ML有优势。
4. 母场景隔离、固定评估家族、未知/等分布负例、选择保护和终点样本量经审查。
5. 训练规模/资源上限、dev选择流程、独立cal与锁定test只用一次的规则另获批准。

任一条件缺失，保持B，不自动进入原512场景、原ICAR-LR六场景或新Geant4。若强经典方法足够或ML没有增量，转向可辨识性/分辨率研究需交用户决定，不由本轮正式改变主线。

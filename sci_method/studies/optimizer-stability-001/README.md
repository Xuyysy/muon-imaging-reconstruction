`verification/run-001` is retained as an unsuccessful verifier attempt: loading
an NPZ key twice selected a general BLAS product between two distinct copies,
instead of the original symmetric Y.T@Y operation, causing bitwise scatter
checks to fail despite identical observation arrays. The verifier now loads
each array once; no scientific tolerance was changed. verification/run-002
passes the corrected check, including independent empty-field groups.
Final verification/run-003 additionally excludes two incidental import caches
from canonical history checks. Those .pyc files were generated by the early
snapshot importer, moved to a recoverable temporary directory, and never staged.
The importer now disables bytecode writes while reading historical snapshots.
All 44 canonical historical files are checked, independently of cache files.

# A：单ROI有限样本检验与适用边界

日期2026-10-29。下文区分[证明]、[数值]和[探索性建议]。

## 1. 随机支配的严格证明 [证明]

假定各事件独立，y_i为零均值四维Gaussian，C_i(u)=C_i0+uD_i；
C_i0已知SPD，D_i已知PSD，u∈[0,u*]，路径、动量、外部响应均已知。
设C_i*=C_i(u*)，用其对称平方根白化，
B_i=C_i*^(-1/2) C_i(u) C_i*^(-1/2)。
由于C_i*-C_i(u)=(u*-u)D_i≥0，故0<B_i≤I，全部特征值b_ij∈(0,1]。
Gaussian正交对角化给出

    Q = sum_i y_iᵀ C_i*^-1 y_i  =d= sum_i,j b_ij Z_ij²,
    Z_ij独立N(0,1)。

在同一组Z上，逐样本有sum b_ij Z_ij²≤sum Z_ij²。因此对任意q，
P_u(Q≥q)≤P(chi²(4N)≥q)。这是随机支配的耦合证明，不是渐近论证。
p=SF_chi²(4N)(Q)满足sup_{u≤u*}P_u(p≤alpha)≤alpha。

当u=u*时B_i=I，Q恰好chi²(4N)，连续情形p恰好Uniform(0,1)。
所以这是**复合零假设边界上精确、内部通常保守**的检验；不能说
所有零假设点的错误率都恰好alpha。若所有D_i=0，则所有u同分布，
检验仍有名义size，却完全不能识别材料变化；需要另报零信息。

物理单位：y为mm，C为mm²，Q无量纲；u为无量纲材料密度乘数，
lambda=.01*u mm^-1是本小诊断的参数尺度，不是材料分类阈值。
每个协方差完整保留共享上游hit诱导的相关项；四个残差不是四个独立事件。

## 2. 何种意义上保守、何种意义上功效低

在零假设内部u<u*，边界参考确有保守性。但若大测量误差使材料响应
接近零，内部size反而可能接近alpha；此时问题是备择功效也接近alpha，
不能把“功效低”都叫作“size过于保守”。

诊断中同一路径响应，C0白化后的单投影散射导数特征值为a1,a2；
x/y各重复一次。模式能量T_m/(1+u a_m)独立chi²(2N)，
Q=sum_m T_m/(1+u* a_m)。因此功效由两个加权chi²和决定。
输出的概率通过Gamma总和与Beta比例的积分确定性计算；128/256节点
差≤1e-8是数值积分核查，不是频率保证的新定理。

sigma=.3mm时a=(.01712593,.64222222)，差别很大。Q把不同材料敏感度的
白化模式等权相加，局部效率相对于score为

    (tr A)^2 / (4 tr A²) = .542976,
    A=C*^-1/2 D C*^-1/2。

该效率是局部信噪比平方/信息效率，不是本有限样本中所需事件数的严格比例。
sigma=1mm时该值.528142；数值限定于本几何、参考u和参数化。

## 3. 更强而同样有限样本有效的经典对照 [证明＋数值]

运行前登记的探索比较固定ua=3>u*，令
W_i=C_i*^-1-C_i(ua)^-1≥0，统计量T=sum y_iᵀW_i y_i。
它对应简单备择对边界零假设的log-LR（加一个已知常数及1/2）。
对固定PSD W，在u≤u*时W^1/2 C_i(u) W^1/2的有序特征值不大于
边界值，故仍由独立chi²耦合得到边界尾概率的随机上界。
边界分布是已知加权chi²，而不一般是普通chi²。

以边界分布校准T，上述检验对整个复合零假设有效；按Neyman–Pearson
引理，在固定简单备择ua上它达到所有边界size≤alpha检验的最大功效。
所以它也在该特定备择上达到复合零假设有效检验中的上界。
这不是对全部u>u*的UMP声明；ua选择影响其他备择的功效。
表中数字是该经典对照的解析分布数值核验，不是新ML算法。

## 4. 明确不能外推的条件

- 多个材料参数均未知且路径重叠时，固定的C0不再已知；不能把拟合其余参数
  当成固定真值后直接使用该p值。
- 未知背景、动量、非零均值/对准、带噪路径、相关事件和非Gaussian尾
  均不自动满足上述保证。真实Geant4物理还未验证此Gaussian模型。
- 任意正负ROI差异不是PSD单调族，边界最不利性不自动成立。
- 由观测选择区域后再把它当固定区域，会破坏单检验声明；需选择保护。

本受控八ROI例仅因各组路径完全互斥，其他ROI在该组导数为零，才保有单ROI
保证；这不是一般三维缪子重建问题。

## 5. 与结构发现的关系

Q可检验“已知基准以上的某一固定ROI非负增强”，不能直接认证任意图像形状。
功效表显示，弱差异和高误差下即使已知真位置也未必支持结构。
同时它有明显经典LR竞争者。仅建立Q的有效性不足以批准CNN训练或宣称论文创新。

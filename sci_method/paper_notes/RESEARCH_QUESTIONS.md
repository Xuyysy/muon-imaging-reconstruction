# 候选科学问题与研究假设

状态截至 2026-10-26 已审查证据，并纳入 2026-10-27 用户确认的阶段状态。以下是研究规划，不是已完成的算法贡献。

## B2：优先探索方向

**物理约束与可辨识性感知的可信机器学习缪子散射成像。**

核心科学问题：在低统计量条件下，如何区分学习型重建中受到观测数据支持的结构，与主要依赖训练先验补出的结构，并在路径覆盖不足或分布外条件下如实表达不可确定性？

当前阶段 0 已建立若干限定模型下的数学审查与负例，但尚未证明机器学习比经典 MAP/统计方法有独立增量。阶段 0 的方法学审查认为，固定候选、同一观测数据、同一物理模型和完全不依赖候选图像的审查器会对 CNN 与 MAP 给出相同审查结论；因此，不能把审查器的检验功效或可靠性归因于 CNN。

### 待检验假设

- **H1：学习型结构候选排序。** 在固定候选/审查预算，并以相同的错误支持风险为约束时，学习型排序能否比经典 MAP、标准化得分或覆盖启发式提出更多可由独立观测支持的真实结构？必须解决候选选择后的有效推断与整幅图像错误支持风险控制。**尚未证明有性能增益或足够的 SCI 新颖性。**
- **H2：学习型初始化。** 在相同物理似然、同一正则目标、相同数值收敛精度和统计审查条件下，学习型初值能否降低包括训练、推断、物理修正和审查在内的总成本？**尚未证明有计算收益或足够的 SCI 新颖性。**

截至 2026-10-27，非神经可行性关卡已获批准但等待结果；它不是 B2 训练、算法验证或论文结论。是否申请小型学习原型，应根据该关卡结果和后续独立审查决定。

### B2 的证伪与终止条件（待审查，不是冻结实验协议）

- 固定审查器实际上与候选图像相关，或选择后推断无法控制时，不得声称候选发现具有统计可信保证。
- 与强 MAP 提议器相比，学习候选排序在同一候选预算和错误支持风险约束下没有可重复的独立收益，则终止 H1。
- 学习初值在达到同一 NLL/KKT/审查精度后不能减少全流程成本，或收益不足以摊还训练及维护成本，则终止 H2。
- 若有限样本有效结构检验或物理模型适用性成为阻断点，先缩窄问题；不以放松风险、改变指标或挑选场景制造正结果。

## A：保留的统计备用方向

**ICAR-LR、Fisher 可辨识性、统计自适应分辨率与可信分辨率界限。**

它关注有限路径覆盖、测量误差、nuisance 与有限事件数下，数据对空间参数或参数对比实际提供多少信息，以及何时应拒绝细化。其数学/合成原型可以作为 B2 的经典基线与方法比较背景。

现有 ICAR-LR 尚未证明全面或稳定优于 BIC、LRT、MAP；原型的均匀材料误细分、弱信号拒绝、不可辨识负例和数值优化失败/修复记录都必须保留。备用方向也不应被表述为已成功算法或已完成真实探测器验证。

## 研究决策约束

1. 训练先验可以影响点估计，但不能把不可辨识方向变成观测证据。
2. 真值 mask、目标标签及 oracle 指标只可用于训练标签隔离或最终评价，不可进入推断、候选细分或结构审查输入。
3. 按独立母场景隔离开发、调参、校准、冻结验证与最终未见测试；同一几何的不同事件流不能自动视为独立场景。
4. 任何性能主张均须与任务相符的强经典基线比较，并计入全流程计算成本。
5. 研究方向、主评价指标和成功标准须由研究者预先确认；本文档列出的终止条件需在具体试验开始前形成经审查的协议。

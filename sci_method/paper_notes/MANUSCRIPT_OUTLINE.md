# SCI 论文结构草案

本大纲为随研究决策调整的素材框架，不是正式论文初稿。当前不固定题目、摘要、创新点、论文结论或投稿期刊；不得提前填入未取得的实验结果。

## 可能主线 B2：可辨识性感知的可信学习重建（优先探索，未冻结）

### 1. Introduction

- 缪子散射成像在低统计量、有限路径覆盖和探测器测量误差下的重建困难。
- 说明点重建与“观测支持的结构”是不同问题；学习先验可能补全图像，但不能创造观测信息。
- 收敛为可证伪问题：学习方法能否在公平风险/计算约束下提供经典 MAP 未提供的结构发现效率或全流程求解收益？
- 研究动机必须由最终选定的假设和最接近文献支撑，不在本阶段宣称方法首创或性能优势。

### 2. Related Work

- POCA、散射统计似然、MLS-EM 与 Bayesian/MAP 重建。
- 可微物理似然、逐径迹模型及神经场/学习型重建。
- 低计数逆问题的学习先验、可辨识性与分辨率边界。
- 可信度、选择后推断、同时错误率和不确定性校准。
- 明确逐版本核对 RHMT v1/NAMT v2 为同一工作；逐篇核查方法、数据、监督方式、泛化测试及可比性。

### 3. Problem Definition and Physical Model

- 定义探测器几何、可观测量、物理散射模型、测量误差协方差和参数单位。
- 区分 data likelihood/Fisher、nuisance 信息及先验/正则化贡献。
- 说明适用范围和可能模型失配：固定动量近似、真实入射谱、hit/track 误差及非 Gaussian 散射等。
- 现有四层深度反例可作为**限定模型内**的不可辨识性动机；不能代替实际探测器验证。

### 4. Method（待确定）

可能内容取决于 H1/H2 后续审查：

- 若研究 H1：候选生成/排序、候选选择机制、独立统计审查或全族风险控制、选择后错误率定义。
- 若研究 H2：学习型初值、固定物理目标函数、后续数值修正及收敛认证。
- 明确训练先验可影响点图像，但不得将不可辨识方向标记为数据支持。
- 真值标签/mask 仅用于隔离训练监督或最终评价；不得进入推断和结构细分决策。
- 本章当前不指定网络结构、损失函数或算法公式，避免将未审查的技术选择写成方法贡献。

### 5. Experiments（待协议审查与冻结）

- 按独立母场景划分 train/dev/calibration/frozen validation/final unseen；同一目标几何的不同事件流不自动视为独立场景。
- 低维确定性数学反例优先于正式训练；先核查信息边界、候选选择有效性和计算收益上限。
- 公平比较至少考虑 PoCA（适用任务）、固定网格 likelihood/MAP 与强正则基线、ICAR-LR/BIC/LRT（对应模型选择任务）、相关 MLS-EM 或可复现近期方法。
- 分开报告三维结构指标与二维投影指标；报告假阳性结构、漏检/拒判、预测数据一致性、风险/覆盖和总计算成本。
- 预先确定各任务适用的主指标、风险目标、场景独立单位与失败条件；不得用测试集反复选主张。
- 当前尚无经批准执行的 ML 正式实验协议；不填入 512 场景、CNN 训练或其他草案计划作为已确定方案。

### 6. Results（目前没有新的 ML 结果）

- 后续按证据顺序报告数学性质、独立数值核验、开发实验和冻结测试，并清楚标识数据来源。
- 当前可供背景使用的内容仅包括：限定 Fermi–Eyges 模型的解析深度不可辨识反例；固定几何下的协方差/Fisher 数值核验；既有 ICAR-LR 合成开发结果与负面记录；有限优化器数值审计。
- 不将上述内容描述为新 ML 方法结果、Geant4 迁移验证或真实实验结果。

### 7. Discussion

- 解释 data-supported 与 prior-driven 结构的区别，以及不可辨识性下的可报告边界。
- 讨论低统计量、路径覆盖、测量协方差、nuisance、模型失配、候选选择偏差和分布外场景。
- 报告负面结果、经典方法可能已足够的情况、拒判的代价和总流程成本。
- 结论强度不得超过实际独立场景与风险验证范围。

### 8. Conclusion（待研究结论形成后撰写）

只总结最终被独立证据支持的贡献、限制及适用条件。若 ML 没有公平基线上的独立增益，应如实收缩/终止 ML 主张，不为预定方向补写正面结论。

## 备用主线 A：ICAR-LR / 可辨识性与统计自适应分辨率

若 B2 的机器学习增量或选择后统计保护无法成立，可重新评估以局部 Fisher 可估计性、有限样本模型选择与可信分辨率界限为主线：

- Introduction/Related Work：从有限统计、误差与路径覆盖提出问题，并与 Bayesian、MLS-EM、BIC/LRT、自适应体素工作比较。
- Method：明确粗细参数、对比方向、nuisance、背景校准、非负约束和优化器认证；不把先验精度写成 data Fisher。
- Experiments：保留既有正/负合成记录，设计新的独立确认集前先审查统计协议；必要时再论证 Geant4 开发性验证。
- Results/Discussion：诚实报告均匀材料误细分、弱信号拒绝、不可辨识负例、优化失败和有限数值边界；不得宣称已优于 BIC/LRT/MAP。
- Conclusion：是否具有可发表的方法学价值仍待独立评估，不能仅以算法可运行作为创新证明。

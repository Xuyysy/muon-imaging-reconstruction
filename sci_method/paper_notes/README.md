# SCI 论文素材库

本目录用于持续积累未来 SCI 论文所需的研究问题、可追溯证据和可调整的文章结构；它是论文素材，不代表论文已经完成，也不等于已确认算法创新或投稿结论。

## 当前研究定位

- 当前优先探索 **B2：物理约束、可辨识性感知的可信机器学习缪子散射成像**。核心问题是低统计量下，如何区分观测支持的结构与主要由训练先验补出的结构。B2 尚未正式冻结为最终主线，且尚无训练结果或已证实的机器学习增益。
- **ICAR-LR、Fisher 可辨识性与统计自适应分辨率**完整保留为统计基线与备用方向。现有 ICAR-LR 原型尚未证明全面或稳定地优于 BIC、LRT、MAP 等成熟基线。
- 论文措辞必须与证据等级一致：解析证明只在其明示假设内成立；确定性数值核验不是物理实验；合成实验不是 Geant4 或真实探测器验证；未运行的假设不能写成结果。

## 研究资料的权威来源

- **GitHub 仓库**是代码、数据、实验配置、运行证据和科学结论来源的权威记录。主张应引用固定 commit SHA 和仓库内原始报告/结果路径，不复制大批原始数据到本目录。
- **Notion**用于管理论文准备进度、研究决策和证据状态，而不是替代 GitHub 的可复现证据。关联页面：[SCI 论文准备｜主张与证据台账](https://app.notion.com/p/406c089052a3819cbc17c9c1f2a5287d?pvs=204)。
- 文献矩阵用于追踪相关工作，不代表已经完成系统综述，也不能仅据此宣称研究新颖性。

## 本目录

- [RESEARCH_QUESTIONS.md](RESEARCH_QUESTIONS.md)：当前候选问题、假设及其未验证状态。
- [CLAIMS_AND_EVIDENCE.md](CLAIMS_AND_EVIDENCE.md)：候选论文主张、证据等级、来源、反证及表述边界。
- [MANUSCRIPT_OUTLINE.md](MANUSCRIPT_OUTLINE.md)：随研究方向调整的论文结构草案。

## 后续更新规程

每完成一个科研阶段，应先由 ChatGPT 根据实际 GitHub 提交及原始记录审查证据，再按审查结果：

1. 更新 `CLAIMS_AND_EVIDENCE.md`，包括正面、负面、失败和未解决结果；每条更新引用固定 commit 与具体文件路径。
2. 仅当研究问题、假设或候选主张发生变化时更新 `RESEARCH_QUESTIONS.md`；论文结构有实质变化时更新 `MANUSCRIPT_OUTLINE.md`。
3. 在 Notion 页面同步论文进度、研究决策和证据状态，并保留对应 GitHub commit 链接。
4. 不把大段原始实验内容重复粘贴进素材库；链接到带配置、输入来源、随机种子、代码版本和哈希的原始记录。
5. 未经独立审查的新分支、新结果或新假设，标记为“待审查”或“待验证”，不并入已证实主张。

# 观测侧软 PoCA-Z 边界：开发集预先固定方案

目标：仅改变现有 `|PoCA-z|<=100 mm` 的硬边界，不改变角度校正、
`theta>=2 mrad`、`theta^2` 截断 3 mrad 或 XY 成像范围。

同一条观测缪子有四层实测击中与已知位置分辨率 sigma。软方案围绕该
实测击中重新扰动 32 次，令 `p_z` 等于 32 次候选 PoCA-z 落入
`[-100,100] mm` 的比例，事件在其**名义观测 XY** 位置的权重为
`min(theta_corrected^2,3^2)*p_z`。硬方案用名义观测 PoCA-z 是否入界的
0/1 权重。sigma=0 时要求两者逐事件、逐图完全一致。`p_z` 只是测量
扰动下的经验通过比例，不是校准的真实散射概率。

本阶段比较同一 Geant4 文件、同一事件子样本和测量噪声下的 U/L/双铝块
开发场景；N=1000/3000/5000，sigma=0/0.05/0.10/0.30 mm，每条件
五次抽样。都在固定 16x16 与 32x32 两个 XY 网格尺度评估投影。
16x16 投影均匀展开到 32x32 后，用同一真值面罩做等面积 IoU、全图质心；
双铝块再报告双目标最弱召回与中间空隙伪影。真值不进入重建规则。

方法实际上仅对 Z 边界的**入选权重**作软化，XY 点并未做概率扩散；
因此本轮是 2.5D 的开发集消融，不得称为完整三维概率体素成像。
即使某个开发条件获益，也不调 32 次扰动数、不重新定阈值；下一步
必须冻结规则，用此前未见的新目标形状和独立 Geant4 种子检验。

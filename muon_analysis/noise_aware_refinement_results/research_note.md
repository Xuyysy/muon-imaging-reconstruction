# 局部有效事件数与噪声门槛：开发实验（含负结果）

本轮沿着“低统计量、物理约束自适应体素”主线，尝试用粗体素内的有效事件数与已知探测器击中误差决定是否细分，而不是固定细分前 40%。输入仍为中心 U 型 Geant4 事件；目标真值只用于事后评分。L 型测试已经暴露了固定细分的缺陷，因此**不能**拿相同 L 型数据再宣称新规则的独立留出验证。本轮结果尚不宜写成论文主方法的有效改进。

## 规则与对照

事件处理与既有脚本一致：2 mrad 散射角下限、3 mrad 权重截断、同一组击中噪声下修正角度。粗体素的有效事件数定义为 `n_eff=(Σw)^2/Σw²`，其中 `w` 是截断后的散射角平方。只有 `n_eff ≥ 2×[1+(theta_noise/3 mrad)²]` 时，才把该粗体素的散射权重按真实 PoCA 落点分配到 8 个细体素；否则均匀分配。`theta_noise=√8×sigma/d`，`d` 是 CSV 中同侧探测器层间距。8 个子格所需的完整分辨率并未由 2 条事件保证；该门槛只是最低可辨识性试探，不是统计显著性判据。

在相同的 1000/3000/5000 条事件子集、5 次抽样、σ=0/0.05/0.10/0.30 mm 条件下，比较粗 16³、固定细 32³、原 40% 细分和新规则。每个条件共享相同原始事件与噪声，实现逐条件配对。共 240 行逐重复结果；非零 σ 下每个参照比较为 45 个配对单元。抽样来自同一 Geant4 文件，不构成独立物理重复。

## 先前失败的 8 事件门槛

最初尝试 `n_eff ≥ 8×[1+(theta_noise/3 mrad)²]`，直觉是每个细子格至少有一条有效事件。但 5000 条完整输入中，一例经角度筛选且落在成像体积内的事件仅约 418 条，粗体素最大 `n_eff=4`；故全部条件细分数为 0，完全退化为粗网格。该结果完整保留在旁边的 `noise_aware_refinement_gate8_results/`，未当作算法改善证据。将无噪声下限改为 2 只依据观测到的有效样本稀疏度和最低可辨识性要求，**未用 IoU 寻优**。

## 修正门槛后的实际结果

5000 条输入事件时，按 σ=0/0.05/0.10/0.30 mm 顺序：

| 方法 | IoU | 平均细分粗体素数 |
|---|---|---|
| 原固定 40% | 0.7171 / 0.5687 / 0.4138 / 0.2277 | 134.2 / 139.0 / 138.4 / 115.2 |
| 完全粗 16³ | 0.6702 / 0.6243 / 0.4698 / 0.2533 | 0 |
| 噪声门槛规则 | 0.6737 / 0.6204 / 0.4698 / 0.2533 | 48.0 / 2.8 / 0 / 0 |

非零 σ 的 45 个配对单元里，相对原固定 40% 细分，噪声门槛规则平均 IoU 差为 +0.0330、IoU 逐对胜率为 80.0%，与完全粗网格的 +0.0331、80.0% 几乎一致。自动窗口定位误差平均**增加**约 1.39 mm（粗网格约增加 1.39 mm）。这表明所谓“改善”主要来自退回粗分辨率，并不是局部自适应细分已经成功。无噪声时原固定 40% 细分 IoU 仍明显更好。σ=0.10 和 0.30 mm 时新规则与粗网格完全相同。

因此，本轮只能得出：在现有 16³ 三维粗网格、严格事件筛选和少量有效 PoCA 点条件下，逐粗体素的有效样本数不足以稳健触发细分；简单加高噪声门槛不够。图 `comparison.png` 与 CSV 用于诊断和复现，**不应只挑含噪 IoU 的正增益写成创新结论**。

## 下一步

先量化沿 z 或邻域聚合后的有效样本数、空间分辨率损失及边界偏差，再考虑 2D/各向异性或邻域共享统计量的细分判据；预先固定规则及定位失败回退条件。规则一旦在开发数据中确定，需生成**新的**未参与设计的目标形状/材料测试，而不能反复使用已看过的 L 型数据。还需报告目标轮廓、全图质心、自动窗口定位与运行代价，不能只优化 IoU。

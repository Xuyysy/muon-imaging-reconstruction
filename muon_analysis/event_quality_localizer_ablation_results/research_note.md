# 固定事件质量规则后的定位器消融

## 设置

重放五个 U 型场景、三个输入事件数、四个击中位置误差水平、各五次重复，在 `hard` 与 `majority` 两种图像上分别运行四个**原有且参数固定**的定位器。每张图只变定位器，未重新选择事件或体素参数。逐行对照旧实验的 IoU、全图质心误差和多尺度定位误差，全部匹配。

主统计使用 `σ > 0` 的每方法 225 张图。以下数据是描述统计，场景与重复不等同于 225 次独立物理实验。

## 非零误差下的总体定位误差（mm）

| 重建图 | 全图质心 均值 / P90 | 固定24格 均值 / P90 | 多尺度 均值 / P90 | 稳健多尺度 均值 / P90 |
|---|---:|---:|---:|---:|
| hard | 13.34 / 28.37 | 14.40 / 31.82 | 20.81 / 56.04 | 20.87 / 53.89 |
| majority | 12.94 / 28.87 | 13.86 / 33.20 | 20.84 / 56.94 | 21.82 / 57.49 |

此处 P90 是 225 张图的误差第90百分位数。固定24格相对多尺度在 hard 图像上有 56.0% 的逐图胜率，在 majority 图像上有 63.6% 的逐图胜率；所以它不是逐例必赢，但应作为强对照。95% 正像素强度截断后的稳健多尺度没有稳定消除问题。

多尺度窗口触及成像边界时，hard 组有 31/225 张图，平均定位误差 43.72 mm；未触边的 194 张图平均 17.15 mm。majority 组分别为 23/225 张、42.80 mm，与 202 张、18.33 mm。这是一个**风险关联**，并不证明触边是唯一原因；图像本身可能已因大噪声失去目标信息。

例如偏心目标、5000 事件、σ=0.10 mm、重复1，majority 的多尺度窗口误差为 34.10 mm，但固定24格只为 3.49 mm；σ=0.30 mm、重复2分别是 64.42 与 8.76 mm。相反，在小目标高噪声失败案例中，固定24格误差仍有 39.95 mm，说明仅换一个更大窗口不能解决所有情况。

## 对研究方向的意义

1. 低统计量事件质量评估和目标定位应分别优化、分别报告；不能把 IoU 改善自动解释为定位改善。
2. 下一个方法学问题是：如何仅根据测量图像识别“不可信的局部窗口”，并在无真值情况下处理它。窗口触边、候选尺度间分数接近、窗口与全图质心差异等可以作为**候选诊断信号**，但不得直接用本轮样例调参后宣称泛化。
3. 固定24格窗口使用了当前最大目标尺度的先验。若未来研究未知尺寸目标，必须把这种先验写清楚，并在新尺寸、新形状上测试。
4. 论文宜在“局限性和失败分析”中加入本轮消融，主结果仍以固定参数的 PoCA、体素与角度筛选为中心。新定位保护方法需要独立场景再验证后才能写成创新点。

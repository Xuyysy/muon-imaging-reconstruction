# 击中误差造成的事件入选与事件属性变化：运行前配对方案

只用 U、L、双铝块三份开发数据；T 型数据已用于冻结规则的独立测试，不参与本分析。沿用既有 N=1000/3000/5000、σ=0/0.05/0.10/0.30 mm、每场景每 N 五次配对抽样和固定随机种子。四层击中误差在同一子样本内使用同一组标准正态抽样。冻结版重建规则不修改。

每条原始输入事件保持稳定行号。令 `S0` 为 σ=0 下通过已固定角度门槛及成像范围筛选的事件集合，`Sσ` 为 σ>0 下通过相同筛选的事件集合。令 `A0` 表示无注入误差时重算得到的 POCA-XY 与角度截断权重，`Aσ` 表示有误差并经既有角度噪声修正后的 POCA-XY 与权重。只改变以下两个因素，构造四张**固定 32×32 XY 直方图**（与体素细分方法无关）：

| 图像 | 入选集合 | POCA 坐标与权重 |
|---|---|---|
| 基线 `I00` | S0 | A0 |
| 仅入选变化 `I10` | Sσ | A0 |
| 仅属性变化 `I01` | S0 | Aσ |
| 完整测量变化 `I11` | Sσ | Aσ |

反事实图像在确定 S 后**不再二次筛选**：例如 `I10` 中某事件的 A0 角度原本未达门槛，仍使用其 A0 权重；超出 XY 网格范围的坐标自然不进直方图。这样四图均可由同一输入事件索引精确配对。`Aσ` 的角度权重采用 `min(max(thetaσ²-theta_noise²,0), theta_cap²)`；`A0` 使用 `min(theta0²,theta_cap²)`。所有图用同一 32×32 XY 边界。

主指标是相对基线总权重的图像 L1 差：`||I10-I00||1`、`||I01-I00||1`、`||I11-I00||1`，以及交互向量 `I11-I10-I01+I00` 的 L1；另报告图像归一化后的形状 L1（防止仅比较总事件权重）、真值仅用于事后等面积 Top-k IoU、S0/Sσ 的交集、流失、新增事件数。L1 大小**不可**解释为互斥因果百分比，因为两因素和交互作用可抵消；逐像素向量恒等式必须通过测试。σ=0 应完全一致，是运行时自检。

σ=0 的 POCA 不是真实散射点；这个反事实分解只量化**当前测量误差模型和筛选规则**对 XY 统计图的作用，不估计真实探测器中的独立物理因果效应。五次抽样来自同一份 Geant4 数据，不作独立样本显著性推断。若有证据表明入选变动重要，也不直接把调筛选阈值视作新算法；后续方案需另行冻结并在全新目标家族检验。

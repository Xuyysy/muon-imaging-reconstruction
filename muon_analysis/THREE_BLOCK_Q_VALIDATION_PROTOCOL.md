# 冻结 Q 门的新形状检验方案：三块阶梯形铁目标

本文件在生成下述 Geant4 事件数据前固定。冻结方法仍是 H（名义 PoCA-z 硬门）、P（32 次击中误差传播的软门）、Q（`h*p+(1-h)*p*n_eff/(n_eff+2)`，16×16 硬门局部支撑）。不改筛选阈值、网格、角度权重、真值评分或 Q 参数。先前 75 mm 十字目标的 Q 主检验失败，不得用本检验覆盖该失败。

## 新物理配置

- `MUON_TARGET_SCENARIO=three_block_iron`：三块互不重叠 G4_Fe 方柱，均为 40×40×75 mm；XY 中心依次为 (−50,−45)、(0,0)、(50,45) mm，z 中心均为 0。三块的 XY 范围分别是 `[-70,-30]×[-65,-25]`、`[-20,20]×[-20,20]`、`[30,70]×[25,65]` mm。
- 原四层探测器、理想平行 4 GeV 源不变。两个全新独立 Geant4 随机流 A/B，宏种子分别为 `(724031,385667)` 和 `(638219,914573)`；各发射 10000 个初级粒子，各自保存完整四层轨迹 CSV。两流不是逐事件物理配对。
- 输入事件数 N=1000、5000；击中位置误差 σ=0、0.05、0.30 mm；各流各 N 无放回抽样 5 次，H/P/Q 在同一子样本和测量扰动上配对。此处复用原验证程序的随机种子生成方式，且本试验不根据结果重抽样。

## 冻结评分与判据

- 主要成像网格为 32×32 XY；以体素中心是否位于三块方柱的 XY 区域内构造评分真值（边界取 `<=`），真值只用于评分。等面积 Top-k IoU 是主要指标；每块召回率及最小块召回率作补充，避免单一 IoU 掩盖丢块。
- **主检验**：N=1000、σ=0.30 mm，A/B 两流的五次平均 Q−P IoU 与 Q−H IoU 均须 `>=0`，且两流 Q 相对 P 的最小块召回率均不得下降超过 0.10。全部条件满足才称“在这个新阶梯形条件通过预定低统计量判据”，绝不称普适成功。
- **低误差安全检查**：N=1000、σ=0.05 mm，两流平均 Q−P IoU 均须 `>=−0.02`。必须单独报告是否通过。
- N=5000、σ=0.30 mm 为预定补充读数，不允许把它替换为主判据；σ=0 必须逐事件满足 H=P=Q。评价同时报告逐次读数、候选数量、均值与源间差异，不以五次相关子抽样做独立样本显著性检验。

这项新形状仍使用同一理想源与探测器，仅增加了一个铁制多块目标家族。即使主判据通过，也不能推断自然缪子、其他装置或所有多目标形状下稳健；若失败，同样要如实保留阴性结果。数据生成后不调整上述任何判据。

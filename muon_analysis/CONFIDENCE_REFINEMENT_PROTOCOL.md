# 细化一致性规则：新场景验证前的冻结协议

状态：**方法与主要评价条件已写定，尚未生成本协议的新场景数据；不是性能结论。**
规则实现：`confidence_refinement.py`。单元测试：`test_confidence_refinement.py`。
当前实现的 SHA-256：`2e11bff1e4172da2bc8d0b98459760f72dc32aa9065f9ff1a4726841fc1259e5`。生成新场景数据前应确认该值未改变；若必须修错，记录原因、重新冻结并保留新的未见场景。

## 研究假设

先前 U、L、双分离铝块结果表明，固定 40% 三维细分容易在少事件或位置误差下把偶然 PoCA 聚集当成真实细节。这里不再规定“细分前 40%”，而问：**一个粗 XY 单元的四个子格偏好，能否在互不重叠的两半事件中重复出现？**如果不能，保留粗尺度；如果能够，只按观测一致性给予部分细节。该分数是经验一致性，不是已校准的置信概率。

输入只包含：通过既定角度修正及筛选的 POCA 三维坐标、截断角权重、已知击中误差标准差 σ、同侧探测器间距 d。算法不读取目标材料标签、真值掩膜、IoU、定位误差，也不调用已生成的 L 或双铝块结果表。

## 已冻结的规则

1. 成像范围和已有角度处理保持不变：XY 每轴 ±90 mm、z 为 ±100 mm；角下限 2 mrad、权重上限 3 mrad，先执行现有的角度噪声底修正。
2. 以 16×16×16 粗网格为基底。对每个粗 XY 单元，沿全部 z 汇总到 2×2 子格，得到四维权重分布 `p`；这是一种 2.5D 投影假设，不声称恢复了 z 方向细节。
3. 用固定随机种子 `20261007` 将同一事件集合随机平分 **4 次**。每次每半边在该粗 XY 单元的有效事件数 `(Σw)²/Σ(w²)` 均至少 **4**（四个 XY 子格各对应一个有效事件的规模）才计算两半各自对均匀分布的偏离。偏离向量的余弦相似度负值截为零；不满足计数条件的拆分贡献零。四次结果直接平均，得到 `[0,1]` 一致性分数 `c`。这些数字在新场景之前固定，不做阈值扫描。
4. 细节幅度 `α = c × n_eff/(n_eff+4) × 1/[1+(θ_noise/3 mrad)²]`，其中 `θ_noise = sqrt(8) σ/d`，换算为 mrad。这里 `+4` 仍对应四个 XY 子格。最终每个粗 z 切片的权重 `W` 按 `(1−α)×W/4 + α×W×p_child` 分给其四个 XY 子格。每个 z 切片总权重守恒；没有额外的固定细分比例、按真值选区或全局 IoU 回退。
5. 同一条件下，所有方法共享原始事件子样本与击中误差抽样；不因本规则耗时或结果好坏改变样本。记录 `active_refined_xy_cells`、`mean_alpha_nonzero` 与运行时间，避免只看图像指标。

## 下一轮真正未见场景（生成前先固定）

使用同材料、同厚度的 **T 型铝目标**，仅改变形状：顶横梁 `x=[−60,60] mm, y=[20,50] mm`；中柱 `x=[−15,15] mm, y=[−50,20] mm`；两者均 `z=[−50,50] mm`，互不重叠。四层探测器、Ideal 4 GeV 平行源不变。Geant4 固定种子 `418951 721093`，发射 10000 个初级缪子；分析从四层完整记录中无放回取 N=1000、3000、5000，各 5 次，位置误差 σ=0、0.05、0.10、0.30 mm；分析抽样随机种子使用既有 `RANDOM_SEED+1129`。T 型真值只在重建完成后用于评价。

比较组：固定 32³、粗 16³、原 40% 三维细分、局部收缩 2.5D、既有保守回退、本规则。所有方案使用同一角度修正、下限与截断权重，不重新扫描参数。主指标为等面积 Top-k IoU（仅仿真评价），辅指标为目标整体质心误差、重建时间与被给予非零细节的 XY 单元数；如果单窗口定位器出现偏移，单独报告，不用它替代 IoU。报告 N×σ 的完整矩阵与逐重复配对差，而不是仅选有利条件。

预先定义的**实用成功标准**（非统计显著性声明）：在 N=5000 时，σ=0 或 0.05 mm 至少一个档位相对粗 16³ 的五次平均 IoU 增益不小于 **0.02**，且该档位至少 **4/5** 次配对胜出；其余三个 σ 档位的平均 IoU 损失均不超过 **0.02**。同时公开所有失败条件。0.02 是在 `[0,1]` IoU 标度上要求可见的增益，并非由 T 型结果调出。五次从同一 Geant4 样本抽取，不能用于独立装置统计显著性推断。

若失败，不在 T 型结果上改规则后再称 T 型为未见测试。可回到 U/L/双铝块开发数据诊断、修改方法，并为修改版重新保留另一个独立场景。无论结果好坏，之后都应补进现有 LaTeX 论文，并保留负结果。

# 击中误差的事件入选/属性反事实分解（开发集）

运行前方案：`../SELECTION_ATTRIBUTE_DECOMPOSITION_PLAN.md`。脚本：`../decompose_selection_attribute_effect.py`。只使用 U、L、双铝块开发场景；每场景 N=1000/3000/5000、σ=0/0.05/0.10/0.30 mm、5 次配对抽样，共 180 个条件。T 型独立检验数据没有参与。

四图依次是基线 I00、仅换入选集合 I10、仅换同一行事件的 POCA-XY 与角度权重 I01、完整有噪声图 I11。报告的 L1 为像素绝对差之和除以 I00 总权重；交互为 I11−I10−I01+I00，其 L1 不是独立贡献率。归一化形状 L1 和等面积 Top-k IoU 是不同量；IoU 的真值只用于事后评价。

## 关键结果

- σ=0 的 45 个配对条件中，四张图严格相同，入选流失与新增为零。
- 135 个非零误差条件中，132 个的仅入选变化原图 L1 大于仅属性变化 L1。仅入选变化的等面积 IoU 在全部 135 个条件中低于无误差基线；仅属性变化在 115 个条件中低于基线。该计数只是同一 Geant4 数据上的重复抽样描述，不能视为独立试验显著性。
- N=5000、σ=0.05 mm：U/L/双铝块的仅入选 L1 分别为 0.313/0.315/0.343，仅属性 L1 为 0.177/0.158/0.198；完整变化 L1 为 0.491/0.565/0.603。基线 IoU 分别为 0.621/0.593/0.568，完整有噪声 IoU 为 0.495/0.489/0.443。
- 同一条件下，U 原本平均入选 410.2 条，有噪声时入选 389.0 条；平均流失 119.0、新增 97.8 条。L 分别为 288.4→319.6、流失 75.2、新增 106.4；双铝块为 262.0→280.2、流失 78.2、新增 96.4。**净事件数并不代表成员稳定**。
- N=5000、σ=0.30 mm：仅入选、仅属性、交互、完整 L1 在 U 型依次为 0.821/0.671/1.072/1.289；L 型为 0.839/0.667/1.388/1.573；双铝块为 0.828/0.645/1.442/1.613。交互不可忽略，绝不能说“筛选贡献 X%、坐标贡献 Y%”。

## 解释与边界

在当前误差模型和已固定筛选规则下，事件成员变化是图像退化的重要描述性来源；并不意味着可以只调整阈值，也不等于证明 POCA 坐标误差无关。高误差时交互项尤其大，可能来自成员改变与属性改变共同作用。四图在确定成员后故意不二次筛选；某些被交换属性的事件可能不满足该属性的原始门槛，因而它们是数学反事实，不是可直接部署的成像流程。σ=0 POCA 不是真实散射点。五次抽样来自相同仿真文件，T 型也不能拿来重新调参后再称为未见测试。

下一步优先拆开**入选变化是由角度门槛还是 POCA 成像边界造成**，并检查事件进出的位置分布；仍只用开发集。若提出新的无真值质量控制规则，需先预注册，再用全新目标家族验证，避免把诊断集当测试集。

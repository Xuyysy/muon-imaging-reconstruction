# 软 Z 边界的事后机制消融：运行前计算方案

这是在查看 `SOFT_Z_GATE_PLAN.md` 的开发集成像结果后提出的分析，
**不是**该实验预先登记的独立检验。只重复使用相同 U/L/双铝块 CSV、
随机子样本、四层击中误差、32 次位置扰动以及两种 XY 网格；不扫描
新阈值、不接触 T 型或新目标数据。

对于共同角度与 XY 门候选事件，令 `h=1[|z_observed|<=100 mm]`，
`p=32 次观测击中扰动所得 Z 入界比例`，原截断角度权重为 `w`。
比较三组图像：

- 硬边界 `H = histogram_xy(w*h)`；
- 只压低原本入界事件 `S = histogram_xy(w*h*p)`；
- 完整软边界 `F = histogram_xy(w*p)`。

另算名义越界事件回流图 `R = histogram_xy(w*(1-h)*p)`，要求
逐像素 `F = S + R`，并逐条件核对 H/F 与上一轮保存的图像指标。
记录角度加权总强度的降权量与回流量，以及同事件 IoU、全图质心
误差；双铝块记录最弱目标召回和空隙误报。IoU 非线性，因此
`IoU(S)-IoU(H)`、`IoU(F)-IoU(S)` 是固定顺序的**描述性差值**，
不能解释为可相加的物理因果份额。

主展示为 N=5000、32x32 XY 网格、sigma=0.05/0.10/0.30 mm；
其余 N 与 16x16 网格全部保存，并报告反例。零噪声须 H=S=F。
若显示只是压低原入界事件形成主要收益，下一步要与更简单的
观测角度/边界距离权重比较；无论结果如何，修改后的方法仍需冻结
并在全新目标及独立 Geant4 种子下验证。

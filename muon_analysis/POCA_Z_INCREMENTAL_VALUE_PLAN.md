# PoCA-Z 不确定度的增量信息：运行前方案

目的：检查逐事件深度不确定度是否比两个简单的观测量（散射角、
观测 PoCA-Z 与 ±100 mm 边界的关系）提供额外的 **PoCA-Z 重复性**
预测信息。此轮不改成像图，也不声称真实散射位置误差。

数据只用 U、L、双铝块开发场景；每次输入 N=5000，击中误差 σ=0.05
或 0.10 mm，沿用先前五次配对抽样。目标是同一缪子的无注入误差和
有误差 PoCA 算法估计之间的 `log1p(abs(delta_z_mm))`。每条事件的
输入只由当前观测击中及已知探测器分辨率得到：

- 基础模型：`log1p(theta_observed_mrad)` 与观测 `abs(poca_z_mm)/100`；
- 增量模型：再加入 `log1p(predicted_z_sd_mm)`，它来自 32 次击中误差传播。

两者均为固定强度 ridge 线性回归，不为结果扫描模型或超参数。对 U/L/
双铝块分别留出一整个场景，训练另两个场景，在留出场景比较事件级
log1p(mm) 的 MAE 与 RMSE。另记录三场景合并后的增量，但不做独立
样本显著性检验：每场景五次子样本仍重用同一 Geant4 CSV 中的事件。

只对无注入误差状态下通过现有筛选的事件做这一诊断；这个条件使用
了仅供评估的参考状态，因此不能把所训练的模型直接部署到未知目标。
即使增量模型胜出，下一步也必须改为完全观测侧可用的规则，并在新的
目标家族上冻结后验证真实成像指标。

# 75 mm 冻结 Q 门的事件数机制诊断（失败结果之后）

本轮在已见 75 mm 厚度验证的**主要判据失败之后**启动，是开发性机制分析，不是 Q 的第二次独立检验。只用四份原 CSV、原分析子抽样和误差传播种子；不生成新 Geant4 数据，不修改 Q 公式、常数 2、16×16 支撑网格或前次 `verdict.json`。原 H/P/Q 的候选数与逐次 IoU 必须核对一致。

对每个原始分析条件报告：硬门占用粗格数、硬门 `n_eff≥2` 粗格数；名义越界软回流质量 `R=Σw(1−h)p`；Q 保留的回流质量 `R_Q=Σw(1−h)p q`；保留比例 `R_Q/R`；回流落在硬门空格和 `n_eff≥2` 格的权重比例；以及回流权重加权的 `n_eff`。这些均可由观测事件计算，不读目标真值。IoU 差只从前次验证结果中读取作评价标签，不能反馈到特征计算。零噪声 R=0，比例记缺失而不是 0。

主展示为 σ=0.30 mm 的 N=1000 与 5000，每材料×流分开；σ=0.05 mm 作补充。两 N 各自从同一 Geant4 CSV 独立抽样，**不是嵌套或同事件的 N 因果配对**；五次抽样也不是独立物理重复。只检查 Q 是否随着可观测局部支撑变化而保留更多回流，以及这是否能解释前轮结果；不训练按 N 的阈值或改判据。若高 N 仍出现 Q<P 或 Q<H，应如实记录。任何事件数驱动的新规则须另留真正未见配置前瞻验证。

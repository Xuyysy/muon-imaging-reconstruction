# 八格组合的条件重采样稳定性

按照 `B1/COMBINATION_STABILITY_PLAN.md` 固定方案，在 U/L/双块开发集复现全部 60 个条件，核对粗图和 neff8 终点后，固定名义八格做各 32 次 bootstrap（共 1920 次）。主指标为各自归一化的细化/粗图相对于其名义图的 L1 重采样距离均值之差；它不读取真值，也不是准确性分数。真实目标掩膜仅用于事后核对归档 IoU。输入事件数不是通过筛选后参与重采样的事件数。

|范围|条件数|负收益条件数|主指标与收益的 Spearman|负收益识别 AUC|
|---|---:|---:|---:|---:|
|全体|60|35|−0.3696|0.7006|
|N=1000，sigma=.05 mm|15|15|−0.0607|不可定义（只有负类）|
|N=1000，sigma=.30 mm|15|5|+0.1429|0.4400|
|N=5000，sigma=.05 mm|15|9|+0.0179|0.4630|
|N=5000，sigma=.30 mm|15|6|+0.0324|0.4444|

主指标总体的区分力没有在分组中稳定重现，提示混合条件差异可能造成总体表象，尚不能证明其能识别同样事件数/误差下的有害细化。不能将 AUC=.7006 称为可部署预测器准确率，也没有训练或测试一个阈值。

更基本的限制：全部 60 条主指标都为正，范围 .01818 至 .08204。在固定选格和总权重归一化下，每个粗格的重采样差值是四子格差值之和，三角不等式保证粗图 L1 不超过细图 L1。因此主指标非负是分辨率增大带来的结构性质，不代表检测到了有害细化。以零作门槛会挡掉本轮所有细化，也会错失有益条件。非负性不排除其幅度将来有信息，但本轮同条件 AUC 未提供这样的稳定证据。

预定辅助指标为固定 k=64/128/256 的重采样 Top-k 掩膜异或比例增量，k 不来自目标真值。N=1000、sigma=.30 的 AUC 为 .74/.26/.92，表现对 k 很敏感；N=5000、sigma=.05 为 .6481/.7685/.5185，sigma=.30 为 .7222/.6204/.6667。所有结果均保存在 `associations.csv`，不得只挑 k=256 的 .92 或 k=128 的 .7685 宣称成功。并列像素的 argpartition 行为也影响结果，粗图特别容易出现并列。

本轮为阴性或尚不充分的可观测代理诊断：稳定性不等于准确性，固定名义八格的条件 bootstrap 不涵盖重新选格、测量误差传播或新物理事件流。没有置信区间、显著性或跨形状独立验证结论。下一步先核查辅助代理的并列像素敏感性（固定、无真值的确定性并列规则），再决定是否值得形成冻结候选。暂不新增回退门槛。

代码：`muon_analysis/diagnose_combination_stability.py`。已有 Notebook 追加展示关联表；论文追加失败机制结果。数据 `bootstrap_draws.csv` 保留逐次重采样距离，`by_repeat.csv` 是每个原条件的均值及事后收益，32 次不是32次独立物理试验。

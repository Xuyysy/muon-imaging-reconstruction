# 简易连续 Z 边界：与 32 次扰动软门的事后对照方案

本方案在查看 `SOFT_Z_GATE_PLAN.md` 及机制拆分的开发集结果后提出，
属于**事后方法比较**，不是新的独立验证；U/L/双铝块已经被用于开发。

三组方法使用前轮完全相同的事件子样本、击中测量扰动、角度噪声底
修正、XY 落点和固定 16x16/32x32 网格：

- 硬门 H：`1[|z_obs|<=100 mm]`；
- 简易门 A：仅用观测 PoCA-z、修正后的观测散射角和已知击中误差。
  当 `sigma>0` 时定义长度尺度 `s=sigma_mm/(theta_corrected_mrad/1000)`；
  令 `A=sigmoid((100 mm-|z_obs|)/s)`。这是无待调比例常数的
  尺度启发式**比较基线**，不是校准的入界概率；`sigma=0` 严格退化为 H；
- 前轮软门 P：围绕实测四层击中扰动 32 次，取 Z 入界比例。

散射权重仍为相同的截断 `theta_corrected^2`，只改变 Z 入选系数。
比较同事件等面积 IoU、全图质心误差；双铝块另看最弱目标召回
和中间空隙误报。记录估计门系数的计算时间，但不把 Python 单次
耗时当成完整系统吞吐量或曝光时间。

输入与前轮一致：每场景 N=1000/3000/5000，sigma=0/0.05/0.10/
0.30 mm，每条件五次。要求 H/P 的逐条件分数与前轮文件完全一致；
零噪声三法一致。不根据结果扫描尺度系数、散射角下限或网格。
即使 A 或 P 在这些开发场景胜出，下一步仍需冻结候选方法后用
新目标家族、独立 Geant4 种子及更现实入射分布检验。

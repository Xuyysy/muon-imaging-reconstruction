# 目标边界子格可信度与 POCA 位置扰动：运行前诊断方案

只读取 U、L、双铝块开发场景。T 型数据已用于旧规则的独立检验，本次不能读取或调参。输入与前两轮一致：N=1000/3000/5000，击中位置误差 σ=0/0.05/0.10/0.30 mm，五次配对抽样。每次从同一 Geant4 CSV 抽取子集，并对四层 x/y 击中使用共享标准正态扰动；五次抽样不是五次独立物理实验。

## 问题 A：边界细节是否可信

以 32×32 真值掩膜的 2×2 子格定义边界粗 XY 单元：恰有 1、2 或 3 个子格在目标内。每格的四个子格散射权重归一化为 `p`，均匀粗网格为 `u=(1/4,...,1/4)`，目标内子格等权归一化为 `q`。只在权重非零、且满足 `n_eff≥4` 的边界格评分；另外报告 `n_eff≥8` 子集，防止低计数解释过度。主诊断为 `L1(u,q)-L1(p,q)`：正数表示观测子格图案比均匀分配更接近真值轮廓，负数表示更远；同时报告目标子格散射质量占比减目标面积占比。真值只进入**诊断指标**，绝不进入重建规则。`q` 是理想二值面积代理，不能等同真实散射密度。

## 问题 B：测量误差对 POCA 的扰动

对同一输入事件按行配对 σ=0 与 σ>0 的重算 POCA，不先用事件筛选结果跨条件强行按位置合并。先报告两端均通过同一角度/成像范围筛选的事件数及 XY 位移的中位数、P90、P95，并另外记录所有有限配对事件的位移统计，以显示筛选偏差。细 XY 子格边长由成像边界直接读取（当前 5.625 mm），只把位移与该长度比较，**不能**把 σ=0 结果当作物理散射点真值。PoCA 单点近似和轨迹近平行不稳定性依旧存在。

不得在本轮诊断中改动已冻结的 `confidence_refinement.py`，也不得把正向开发集指标写成独立验证的新方法。输出完整条件 CSV、场景汇总和图；若边界接近真值的证据不稳定，应停止单纯加细，并研究 POCA 定位与散射权重模型。

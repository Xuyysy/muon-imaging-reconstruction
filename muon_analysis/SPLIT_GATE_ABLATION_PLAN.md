# 分半计数与收缩消融：运行前固定的开发集分析方案

本分析只读取 U、L、双铝块三类**开发**场景；不得读取 T 型 CSV、结果或真值，也不得改动已冻结的 `confidence_refinement.py`。目的是区分“门槛太严格”和“细节权重太小”两种解释，不把开发集上的最高分当作独立验证。

输入条件与上一轮门控诊断一致：每场景 N=1000/3000/5000，击中位置误差 σ=0/0.05/0.10/0.30 mm，五次配对抽样，共 180 个条件。四种事先规定的处理是：

| 名称 | 每半最小有效事件数 | 是否保留 `n_eff/(n_eff+4)` 收缩 |
|---|---:|---|
| frozen4_shrink | 4 | 是，必须逐像素复现冻结实现 |
| gate2_shrink | 2 | 是 |
| gate4_no_shrink | 4 | 否 |
| gate2_no_shrink | 2 | 否 |

所有处理保留相同四次分半、固定种子、非负余弦一致性、噪声因子、角度截断权重、XY 两倍分辨率和逐 z 层权重守恒。另列粗 16³ 网格作基线。`no_shrink` 只移除有效事件数的收缩项，不移除噪声因子。真值不参与重建，仅用于事后等面积 Top-k IoU。

每个配对条件记录：通过门槛的粗 XY 单元数、正一致性单元数、非零细化权重单元数、相对粗图像 L1 变化、Top-k 改变像素数、等面积 IoU，以及相对粗网格的 IoU 差。汇总均值、标准差和胜/平/负次数，分别报告三场景及噪声条件；不要只挑最有利的点。若降低门槛带来更强图像扰动但轮廓没有稳定提升，结论应写成“已定位瓶颈但尚无有效改进”。

本轮不作投稿意义上的显著性或跨装置推断：五次样本来自同一份 Geant4 数据的再抽样。T 型已被上一轮使用，修订规则需要另一个真正未见的目标家族测试。

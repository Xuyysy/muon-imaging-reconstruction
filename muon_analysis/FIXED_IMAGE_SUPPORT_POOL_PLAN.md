# 固定成像事件的局部支撑池反事实消融（事后诊断）

## 要分离的效应

上轮嵌套 N=1000→5000 时，Q 的局部支撑估计和最终成像事件同时改变。本轮**固定前 1000 条成像事件**，仅将估计 16×16 硬门有效数的事件池由前 1000 扩充为完整 5000 条。辅助 4000 条只计算观测角度/XY 候选、硬 Z 门和局部有效数；不得进入最终 32×32 图像、P/H 对照或真值评分。

## 预先固定的实现与读数

- 复用 `run_nested_count_gate_diagnostic.py` 的四份已见 75 mm 铝/铁十字 CSV、抽样顺序、5 次重复、八坐标标准正态扰动和 PoCA-z 传播随机种子。N=1000 是 5000 的严格前缀。
- 支撑池取 `S∈{1000,5000}`，不扫描中间数量或收缩参数。成像事件固定 `N_image=1000`。计算 Q 的公式不变：`h*p+(1-h)*p*n_eff/(n_eff+2)`；`S=1000` 必须与冻结实现及上轮已归档的 N=1000 Q/P/H IoU 完全一致。
- 对同一 1000 条事件核对 H/P 图像逐像素相同，Q 才允许变化。σ=0 时 H/P/Q 全部相同。
- 主要描述读数为 σ=0.30 mm 的 `IoU(Q,S=5000)-IoU(Q,S=1000)`、`Q-P`、P 回流保留比例，以及五次配对符号；σ=0.05 mm 作为敏感性检查。
- 为衔接上一轮，同时保存固定顺序的加法路径：`(图1000,池1000)→(图1000,池5000)→(图5000,池5000)` 的 Q−P 差。第一段仅变支撑，第二段在较大支撑池下加入成像事件。分解数值严格相加，但依赖选定顺序，**不是唯一的因果贡献比例**。
- 所有辅助事件与成像事件来自同一物理 CSV。这个软件反事实可以隔离**给定成像事件时改变支撑估计的直接作用**，但不是对新样本的独立验证，也不是现实中免费的额外曝光：辅助缪子依然需要被探测。它不能单独证明这种改变带来泛化收益，更不能为新 Q 规则调参。

若扩充支撑池使固定 1000 条图像的 Q−P 显著下滑，只能说明原 Q 的支撑项是上轮事件数趋势的一个可能机制；完整 5000 条成像结果中的其余变化还包含新增成像事件与 Top-k 竞争效应。

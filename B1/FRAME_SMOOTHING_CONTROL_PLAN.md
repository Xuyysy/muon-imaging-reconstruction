# 方框软深度传播与廉价空间平滑对照（运行前方案）

沿用原方框两流120条事件/误差条件、各16/32网格，共240条配对图像条件。H/A/P均不修改；新增S：在H原生XY网格上做一次固定物理标准差5.625 mm（32网格一像素）的可分离高斯平滑，16网格为0.5像素、32为1像素，支持半径ceil(3*sigma_pixels)。有限成像域内按每个源像素归一化核列，严格守恒总权重；不向成像域外丢质量，不读取目标真值，不扫描核宽。16格平滑后再均匀映射32格评分，不能先映射再平滑冒充原生16格。

S在所有误差档位（含零误差）都执行；零误差仍只要求H/A/P一致，不能要求S与H一致。保留原硬IoU、分数IoU、连续代理、目标内权重和总图权重比，完整报告所有条件。P-S主对照沿用N=5000、grid32、sigma=.05/.10的两流，同时报告高误差和低统计量。

成本：在相同已计算的观测候选、角度权重、名义XY、观测z及误差参数上，分别独立重建H/A/P/S的两个网格。S计入H门及H直方图成本；P计入32次传播；A计入解析门。每条件每方法先热身一次，再三次计时，方法次序循环轮转。排除共同候选/径迹预处理、Geant4、I/O、评分、图绘和导入；记录方法增量重建的wall time，不冒称全流程耗时或峰值内存。P一次传播复用到两个网格，不在每网格重复付费；全部方法同样同时输出两个网格。

计时产生的H/A/P/S图须匹配本轮名义图；旧720条H/A/P得分及新评分匹配上轮归档。测试平滑非负、质量守恒、零图保持零、原生16映射一致、核宽不依赖真值。两流旧数据仍是开发/回顾性对照，不是新独立验证。若S较好不事后改P参数或核宽；若P较好也不能只凭方框证明其普适优势。

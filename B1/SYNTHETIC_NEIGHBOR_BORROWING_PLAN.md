# 固定总事件预算的两粗格借用：执行前方案

本轮仍只研究已知概率的四子格合成统计模型，不运行Geant4，
不将邻域信息当成免费新增事件。两相邻粗格A/B分别有n_A、n_B
条独立事件，总预算N=n_A+n_B固定。A稀疏、B较密：
(1,8)、(2,8)、(4,16)、(8,32)，每场景/预算重复10000次。
邻格B的事件不会计入A自身事件，且同一A/B样本配对所有方法。

## 结构场景

1. 两格均均匀：检验盲目借邻居制造随机细节。
2. 两格同为(.7,.1,.1,.1)：共享真实方向的可借信息。
3. A为(.7,.1,.1,.1)，B为旋转一次的(.1,.7,.1,.1)：跨边界错向。
4. A为(.5,.5,0,0)，B为(0,0,.5,.5)：不重叠边界。

该四子格方向在两个物理粗格内按同一局部坐标比较，实际探测器
若几何/接受度改变还会多一层错配；本轮不模拟探测器或散射。
独立随机种子固定，每配置10000次。全部等权；变权留待下一步，
不能将本轮结论外推到角度平方权重或PoCA。

## 无真值方法与诊断参照

每个格独立基线I：(4u+c_i)/(4+n_i)，继承此前的四子格均匀先验。
全共享P：(4u+c_A+c_B)/(4+n_A+n_B)，两格共用一幅子格比例。
限额借用L：从邻格最多借相当于4条的伪计数，仍归一化本格图。
观测门G：在L上用两格经验分布差D与两格观测方差V调借用份额：

    gate = 1              if D <= V
           V/D            if D > V, V > 0
           0              if V = 0, D > 0

单事件无可估计方差，约定用均匀先验总散度0.75作该格V；n>1
使用(1-||c/n||²)/(n-1)。该约定不是自适应学到的边界，
只是测试“只靠观测是否足以安全借用”的开发性规则；不调阈值。
共享形状“oracle”可由真值选择P或I，只作诊断，不可部署。

额外记录A的“可定向观测”反事实：把同样N条事件都从A采集后用I。
它与P/A有相同总预算，却需要能控制目标区域通量；真实宇宙线
一般不能定向获得此数据，因此不是实际可用的基线，只说明
完全共享结构时借来的独立同分布事件与在A新增事件的统计等价。

## 预定检查与停点

所有方法无真值、单格输出非负且和为1，乘本格总权重后守恒；
G借用不超过L，L不超过P的邻居伪计数。对同结构、边界结构
逐格给出平方风险、配对Monte Carlo标准误及借用份额，
不能只报告稀疏A获益而忽略B或越界代价。

开发筛查：G在共享偏向场景的(1,8)、(2,8)两档需改善A；
在不重叠边界的四档，A和B均不得劣于各自I基线
（均值差容差1e-12）。若失败，停在合成层，不进入Geant4。
此判据是开发筛查，不是统计显著性或未见物理验证。
若通过，还需等权以外测试、同事件固定S强基线及新Geant4配置。

# 已见 Geant4 档案的邻格证据覆盖率审计（事后诊断）

本计划在统计前固定审计口径。输入仅为 `muon_analysis/single_cell_refinement_signal_results/cells.csv` 与 `by_repeat.csv`；不重跑 Geant4、不修改现有 POCA 或自适应体素重建，也不搜索最优阈值。U、L、双铝块均已被看过，只能视为开发档案，不能称为新独立验证。

## 观察单位及主条件

每个场景、输入事件数、噪声档与五次子抽样中的一个占用粗 XY 格为一条“格-抽样记录”。主条件为输入 N=1000/5000 与击中位置误差 σ=0.05/0.30 mm，共 3×2×2×5=60 个场景-条件-抽样。五次来自同一份场景 Geant4 CSV 的相关子抽样，不作独立重复或显著性检验。

定义 A 为 `1 ≤ cell_event_count ≤ 7` 的稀疏占用格。在同一 16×16 粗网格的四个正交相邻格中寻找 B，条件为 `n_B ≥ max(4, n_A+1)`；本格与邻格均只使用观测 PoCA 落点计数。若多个 B 合格，以计数最多者为记录用 B，同数时按格坐标字典序。无 B 记为“邻格支持不存在”。本格留出评分是否可用由已有 `heldout_log_gain` 是否为有限数确定；不可用是缺失，绝不当作 0 或负分。两者同时存在才计入“联合覆盖”。留出评分只由本格分半子格计数得到，本审计不把其符号当成已验证的边界判别器。

## 预定输出与检查

按场景和 N、σ 分层，以及按 N、σ 合并场景，给出稀疏格数、邻格支持数、留出可评分数、联合覆盖数及对应比例；另按 A 的计数 1、2–3、4–7 描述缺口。对条件键和格键检查唯一性，逐条件用 `by_repeat.csv` 的 `occupied_cells` 校核档案行数，并断言联合覆盖不超过任一单独覆盖。来源文件记录 SHA-256。结果只写 JSON、简短研究记录和静态科研图，不编辑或复制原始 CSV。

## 解释边界及停点

覆盖率只是已有无真值证据能否进入候选决策的**必要条件**，不是邻格可借的充分条件，更不是 IoU/边界保持的改善。若低统计量高误差的联合覆盖很低或为零，则暂停用当前两个观测量搭建邻格借用规则；即使覆盖较高，先前已发现本格留出分数区分有用边界不稳定，仍不能直接推进方法验证。仿真真值字段 `target_child_count`、`single_cell_iou_gain`、`positive_gain`、`negative_gain` 不参与选格、邻格选择或主统计。
